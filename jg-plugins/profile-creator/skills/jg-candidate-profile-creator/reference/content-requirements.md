# Candidate Profile — Content Requirements

Produce a one-page candidate profile that gives a client enough depth to evaluate a candidate for a specific role — matching the detail level of a resume, not a thin summary. Populate every field from the candidate's actual materials; never invent metrics, employers, or credentials.

**Anonymize client names.** Real past-client/employer names never appear on the page — describe each engagement by industry or project type instead (e.g. "Healthcare Payments Platform" rather than the client's name). The only real client name allowed is the current pitch target, in the footer's "Submitted for" line.

## Header
- Candidate name (first name + last initial only — e.g. "Andrew H.")
- Role title being pitched (e.g. Senior Software Engineer)
- Availability status (e.g. Available Now)
- One-line descriptor: specialization + tenure with JG (e.g. "Java-Focused Backend & Cloud Engineer · With Jahnel Group since 2019")

## Summary paragraph (3–4 sentences)
- Who they are, years of experience, current/anchor engagement
- Core technical blend (languages, platforms, focus areas)
- A trust/soft-skill note grounded in real client feedback (ownership, communication, long-term reliability)

## Industries strip
- The 2–4 client industries they've worked in, for quick relevance scanning, named generically not by client (e.g. Healthcare Payments · Retail & Fulfillment · Financial Services)

## Experience & Project History (reverse-chronological, 3–4 entries)
Each entry:
- Project/engagement title
- Date range
- Role held + client industry
- 4–6 strong, specific achievement bullets — action-led, drawn solely from the candidate's real work; emphasize scope, ownership, systems built, and outcomes. No fabricated numbers.
- A tech-stack line for that engagement

## Stats (3 metric callouts)
- Quantifiable, verifiable facts only (e.g. Years with JG, # client industries, a standout capability like "GDPR compliance depth")

## Skills (categorized, fully listed)
- Group all skills into categories (e.g. Languages & Frameworks; Cloud, Platforms & Tools; Security & Compliance)
- List every relevant skill — no ratings, no strong/weak emphasis
- Category *order* is role-driven: lead with the category most relevant to the target role (e.g. front-end skills first for a front-end role)

## Education
- Degree + institution

## Fun fact
- One short personal line

## Footer
- Confidentiality line + jahnelgroup.com

## Voice
- Plain, direct, confident; builder-to-builder. No filler or marketing fluff.
